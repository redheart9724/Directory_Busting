Client-side recon tool for authorized VAPT engagements — path discovery, soft-404 baselining, lightweight tech fingerprinting.
Scope & legality: Only run this against targets you have explicit written authorization to test. This tool performs non-destructive path/content discovery only — no payload injection, no credential brute-forcing, no WAF-evasion logic. Respect the engagement's rate limits and robots.txt.
⚠ Direct requests are being blocked by the browser's CORS policy. This target doesn't send Access-Control-Allow-Origin headers, so a browser page cannot read status codes or bodies from it cross-origin — this is a hard browser security rule, not a bug in the scan logic, and it's why the run auto-stopped instead of producing 1,000 identical failed rows. To get real directory-busting results you need a tiny proxy you control and are authorized to route this engagement's traffic through. A minimal one (Cloudflare Worker, free tier): 
export default {
  async fetch(req) {
    const target = new URL(req.url).searchParams.get('url');
    if (!target) return new Response('missing url', {status:400});
    const r = await fetch(target, {redirect:'follow'});
    const body = await r.arrayBuffer();
    return new Response(body, {status:r.status, headers:{
      'Access-Control-Allow-Origin':'*',
      'content-type': r.headers.get('content-type')||'text/plain'
    }});
  }
}
Deploy that, paste its URL + ?url= into the "CORS proxy prefix" field below, and re-run.
