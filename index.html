🛰️ Endpoint Fuzzer & Tech Fingerprint

Client-side recon tool for authorized VAPT engagements — path discovery, soft-404 baselining, lightweight tech fingerprinting.
Scope & legality: Only run this against targets you have explicit written authorization to test. This tool performs non-destructive path/content discovery only — no payload injection, no credential brute-forcing, no WAF-evasion logic. Respect the engagement's rate limits and robots.txt.
⚠ Direct requests are being blocked by the browser's CORS policy. This is enforced by the browser itself — the target doesn't send Access-Control-Allow-Origin, so no client-side script can read its status codes or bodies cross-origin. No amount of retrying or cleverer fetch logic gets around this; it needs a proxy in the loop. Don't route engagement traffic through a public third-party CORS proxy — that leaks the client's data to a service you don't control. Instead run this tiny proxy on your own machine (stdlib only, nothing to install): 
python3 -c "
import http.server, urllib.request, urllib.parse as up
class H(http.server.BaseHTTPRequestHandler):
  def do_GET(self):
    t = up.parse_qs(up.urlparse(self.path).query).get('url',[None])[0]
    if not t: self.send_response(400); self.end_headers(); return
    try:
      r = urllib.request.urlopen(urllib.request.Request(t, headers={'User-Agent':'VAPT-Scanner/1.0'}), timeout=10)
      body, status, ctype = r.read(), r.status, r.headers.get('Content-Type','text/plain')
    except urllib.error.HTTPError as e:
      body, status, ctype = e.read(), e.code, 'text/plain'
    except Exception as e:
      self.send_response(502); self.end_headers(); self.wfile.write(str(e).encode()); return
    self.send_response(status)
    self.send_header('Access-Control-Allow-Origin','*'); self.send_header('Content-Type', ctype)
    self.end_headers(); self.wfile.write(body)
http.server.HTTPServer(('localhost',8787), H).serve_forever()
"
Run that, keep it open, then set the proxy field below to http://localhost:8787/?url= and hit Test proxy. (No Python handy? A Cloudflare Worker doing the same relay works too — same shape, just hosted; only use that for public/non-sensitive targets since the request then leaves your machine.)
